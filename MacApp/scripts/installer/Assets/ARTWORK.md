# Echo installer characters

`echo-character.png` is a transparent image generated with the built-in image
generation tool on October 29, 2026. The separate character is composed around
native draggable icons using AppKit; there is no generated full-scene background.
The original output remains in the local generated-images directory.

## Final prompt

Create ONE small whimsical 3D brand character as an isolated transparent PNG
asset for Echo, a premium macOS voice dictation app. Not a background, poster or
scene. The character is made from two overlapping smooth vertical pill-shaped
glass capsules: a shorter luminous warm peach/pale rose capsule on the left and
a taller saturated cobalt-blue-to-periwinkle capsule on the right, like two
gently overlapping speech/sound shapes. They form a compact recognizable
silhouette. Add only two small expressive dark oval eyes on the front peach
capsule, angled slightly toward the viewer, friendly and clever, not childish.
The cobalt capsule has a polished reflective bevel, dark cobalt lower half and
pale lavender top; the peach capsule has softly frosted translucent highlights.
No arms, legs, mouth, text, letters, logo mark, microphone, keyboard, floor,
container, extra floating objects or drop shadow. Tiny controlled dimensionality,
tactile industrial-design surfaces, elegant charming mascot for a Mac installer.
Body tilted gently 12 degrees as if floating/moving. Full character with generous
transparent margin, no clipping. Crisp clean silhouette, photorealistic materials,
not flat illustration. The character should remain clear when shown at only
60 pixels tall.


## Pose variants

The following three transparent assets were generated on October 29, 2026 with
`echo-character.png` supplied as the reference. The original character plus these
three poses form the four-character family. They retain the same peach and cobalt
capsules, glossy materials, compact silhouette and small dark eyes. No generated
text, folder or UI is included.

- `echo-flying.png`: side-on flight toward the right; the capsule pair tilted
  almost horizontally, peach face leading and both eyes looking ahead. No arms,
  legs, streaks, shadow or background. Full body with transparent margin, readable
  at 60 pixels.
- `echo-wink.png`: upright with a small lean left, one eye a closed curved wink
  and one open dark oval; a tiny glass highlight. No mouth, limbs, props or scene.
- `echo-peek.png`: curious three-quarter view toward the left, gently tilted,
  two oval eyes looking upward-left; the peach capsule slightly lower so the
  taller blue capsule peeks above it. Full body visible to allow the native
  Applications icon to partially cover it during composition. No floor, shadow,
  props, additional characters, text or UI.

Each prompt requested the same supplied mascot and materials, true transparency,
generous unclipped margins and a silhouette readable at 60 pixels. Originals
remain in the local generated-images directory; these copies are release inputs.
