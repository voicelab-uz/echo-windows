# Quick start

Install `VoiceLab-Echo-Setup-x64.exe`, or extract the entire portable package and run `VoiceLab.Echo.exe`. The EXE requires the supporting files beside it.

1. Complete onboarding, microphone setup, browser sign-in, and the voice practice.
2. Focus the text box where you want to dictate.
3. Press **Win + Alt + Space** once to start recording.
4. Speak, then press the same shortcut again to finish and transcribe.
5. Echo attempts to paste the result. History saving and automatic pasting can be configured in Settings.

## Workspace

- **Home:** recent transcripts and Search history. **Ctrl+K** opens History search from anywhere.
- **Statistics:** account and device usage.
- **History:** search, copy, and edit transcripts. Copy briefly changes to Copied. Account transcript deletion is unavailable; Clear local copies leaves account history intact.
- **Vocabulary:** switch between Vocabulary and Snippets tabs.
- **Notes:** write in the editor; changes save automatically. The three-dot menu contains folder, pin, save, discard, and delete actions.
- **Upload audio:** transcribe an existing recording.

Settings includes the shortcut, activation mode, microphone, theme, dictation language, and text insertion options. Dictation supports automatic detection plus explicit English, Uzbek, and Russian choices; interface translation is not complete.
